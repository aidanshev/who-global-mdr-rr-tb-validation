# Release checklist

- [x] Public repository created and readable.
- [x] Raw data and third-party image binaries excluded.
- [x] Exact prospective lock and prediction hash materialized.
- [x] Original next-release evaluator materialized.
- [x] Public-tree audit and GitHub Actions safety workflow present.
- [x] Citation metadata present without a false DOI or unreleased version.
- [ ] Exact hash-matched V2 model-development source files listed in `manifests/PROSPECTIVE_LOCK.json` recovered and materialized.
- [ ] Full frozen tree re-audited after recovery.
- [ ] Explicit software license selected by the code owner after upstream-license review.
- [ ] Final manuscript-to-code consistency check performed immediately before submission.
- [ ] Immutable Git tag and GitHub Release created after frozen-code completion.
- [ ] Release archived with a preservation DOI and DOI inserted into repository/manuscript citation metadata.

Until the missing V2 files are recovered, release only as a clearly labeled partial frozen-code/provenance deposit.
