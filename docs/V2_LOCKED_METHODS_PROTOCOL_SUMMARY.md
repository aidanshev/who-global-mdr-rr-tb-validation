# V2 locked methods protocol summary

Primary endpoint: annual reported RR/MDR notification rate. Secondary: WHO-modeled MDR/RR incidence. Testing-adjusted: reported RR count / rifampicin-resistance test results. Validation used nested rolling-origin tests, a fixed-origin two-year task, Mondrian conformal intervals, multi-family/seed/alpha alert consensus, injected persistent surges, and a frozen prospective 2025 evaluation with no retuning.
